# Demo scripts

These are **not** tests: they are the runnable snippets used in the top-level
`README.md`, kept here so the documented output can be regenerated by hand.

They sleep for several seconds on purpose and print instead of asserting, so
`pytest` is told to ignore this directory (see `pytest.ini`).

```bash
python test/demo/prof_function.py      # @profiler, repeated calls
python test/demo/prof_cm.py            # magic_profiler, nesting
python test/demo/prof_lbl.py           # @profiler_lbl
python test/demo/demo_get.py           # data access API
python test/demo/demo_globMemTime.py   # bare import, global timer only
python test/demo/demo_all.py           # everything at once
python test/demo/demo_logger.py        # logger -> custom_profiler.log (ONE case per process)
```

The automated suite lives one directory up: `pytest`.
